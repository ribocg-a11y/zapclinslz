# ZapClin — Reel Instagram 30s

Vídeo vertical **1080×1920 (9:16)**, ~30 segundos, gerado a partir da arte do capacete e dos textos da legenda.

## Arquivos

| Arquivo | Descrição |
|---|---|
| `zapclin_instagram_reel_30s.mp4` | Reel pronto para upload |
| `instagram_caption.txt` | Legenda sugerida para o post |
| `zapclin_flyer_source.jpg` | Arte de referência |
| `zapclin_caption_source.jpg` | Print da legenda de referência |

## Como regenerar

```bash
pip install pillow
python3 scripts/generate_zapclin_reel.py
```
